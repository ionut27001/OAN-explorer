# OAN — marca

**Ambrazura.** Un O care privește printr-o fantă verticală — fereastra de veghe dintr-un zid.
Se citește simultan ca literă, ca deschizătură și ca ceva care stă de pază.

Fanta are vârful rotunjit și baza tăiată drept. Asimetria nu e stil: simetrică, forma devine
butonul de pornire, și asta a fost respins la a doua rundă de schițe.
